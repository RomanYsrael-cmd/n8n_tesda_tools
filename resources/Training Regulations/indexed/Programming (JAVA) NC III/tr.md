# PROGRAMMING (JAVA) NC III - Indexed Training Regulation

The qualification develops competencies to develop or write program codes using a personal computer or workstation as part of a systems development team, including object-oriented analysis/design in Java and creation/fine-tuning of Java applications using OOP concepts.

## Competency groups

- Basic: 6 units
- Common: 2 units
- Core: 2 units
- Total nominal duration: 240 hours
